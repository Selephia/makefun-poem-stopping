A program that writes one short poem about stopping — about agency, the power to stop and to stay. Everyone applauds the arrow; no one thanks the hand that chose to hold it still.

## Run it

```sh
OUTPUT_DIR=/tmp/out python3 main.py && cat /tmp/out/entry.txt
```
